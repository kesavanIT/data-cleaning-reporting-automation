# Data Cleaning & Reporting Automation

## Project Overview
This project automates data cleaning, preprocessing, sales reporting, and visualization using Python.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Key Features
- Handles missing values using median imputation
- Removes duplicate records
- Standardizes inconsistent text values
- Generates city-wise and category-wise sales reports
- Visualizes total sales by city
- Exports cleaned data and reports as CSV files

## Project Files
- `raw_sales_data.csv` — Original dataset
- `cleaned_sales_data.csv` — Processed dataset
- `city_sales_report.csv` — City-wise summary
- `category_sales_report.csv` — Category-wise summary
- `data_cleaning_report.csv` — Cleaning statistics
- `Data_Cleaning_Reporting_Automation.ipynb` — Project notebook

## Conclusion
This project demonstrates how Python can automate data preprocessing and reporting, improve data quality, and reduce repetitive manual work.
